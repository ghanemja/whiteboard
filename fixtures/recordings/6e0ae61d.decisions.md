### Decisions

#### D1 · Where expiry is stored (accepted)

- **Chose:** Absolute expiresAt timestamp on each link record
- **Over:** Store expiresInDays and compute on read; Background sweeper deleting links
- **Why:** One comparison on read, no timers; expired entries stay in memory (acceptable for an in-memory store).
- **Check:** test 'expired links return 410 and stop redirecting' passes
- **Proof:** ✓ passed: ok 11 - expired links return 410 and stop redirecting
- **Evidence:** src/store.js keeps links in a Map with createdAt
- **Affects:** store.js

#### D2 · Testable clock (accepted)

- **Chose:** createStore({ now = Date.now }) injected clock
- **Over:** Fake timers via node:test mock; Real sleeps
- **Why:** Deterministic tests without waiting days; tiny API change.
- **Check:** test 'expired links return 410 and stop redirecting' passes
- **Proof:** ✓ passed: ok 11 - expired links return 410 and stop redirecting
- **Evidence:** createServer(store) already accepts an injected store (src/server.js)
- **Affects:** store.js, server tests
- **Builds on:** D1

#### D3 · Expired link response (accepted)

- **Chose:** 410 Gone on redirect, not counted as a click; stats still 200 with expiresAt
- **Over:** 404 like unknown codes; Delete on expiry
- **Why:** 410 tells clients the link existed but is over; stats remain useful to the owner.
- **Check:** test 'expired links return 410 and stop redirecting' passes
- **Proof:** ✓ passed: ok 11 - expired links return 410 and stop redirecting
- **Evidence:** server.js returns 404 for unknown codes
- **Affects:** server.js
- **Builds on:** D1

#### D4 · expiresInDays validation (changed)

- **Chose:** Optional number, 0 < n ≤ 365 (fractions allowed); otherwise 400. Omitted = never expires (expiresAt null)
- **Before:** ~~Optional positive number (fractions allowed); otherwise 400. Omitted = never expires (expiresAt null)~~
- **Over:** Integers only; Default expiry; Uncapped
- **Why:** User asked for a 365-day cap to catch typos like 36500; omitted keeps current clients working.
- **Changed because:** you asked: cap it at 365 days, so nobody sets a link to expire in a century by mistake
- **Check:** test 'rejects invalid expiresInDays' passes (includes 366 and 0)
- **Proof:** ✓ passed: ok 12 - rejects invalid expiresInDays
- **Evidence:** alias validation pattern in src/server.js returns 400
- **Affects:** server.js
